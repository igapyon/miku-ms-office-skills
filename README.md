# miku-ms-office-skills

`miku-ms-office-skills` is an Agent Skills package for choosing and using the
miku-soft Microsoft Office and Markdown conversion tools from AI agent
workflows.

The installable skill is `igapyon-miku-ms-office`.

## Scope

This repository is a workflow adapter. It does not implement Office conversion
logic. Conversion behavior belongs to the upstream miku-soft repositories and
their runtime artifacts.

The initial scope covers these upstream families:

- `miku-xlsx2md` and `miku-xlsx2md-java`
- `miku-docx2md` and `miku-docx2md-java`
- `miku-pptx2md` and `miku-pptx2md-java`
- `miku-md2xlsx` and `miku-md2xlsx-java`
- `miku-md2docx` and `miku-md2docx-java`
- `miku-md2pptx` and `miku-md2pptx-java`

## Quick Start

1. Confirm bundled runtime artifacts under
   `skills/igapyon-miku-ms-office/runtime/`.
2. Run `npm test`.
3. Run `npm run build:bundle`.
4. Install `bundle/miku-ms-office-skills/skills/igapyon-miku-ms-office` into
   your skill home.
5. In conversation, explicitly start with `igapyon-miku-ms-office` or
   `miku-ms-office`.

## Repository Notes

- `skills/igapyon-miku-ms-office/` is the canonical skill source.
- `skills/igapyon-miku-ms-office/index.json` is generated discovery metadata.
- `skills/igapyon-miku-ms-office/runtime/` contains bundled Node.js `.mjs` and
  Java `.jar` runtime artifacts from the upstream converter releases.
- `workplace/` is a local scratch area. Only `workplace/.gitkeep` is tracked.
- `bundle/` is generated by `npm run build:bundle` or
  `npm run build:bundle:zip`.

## AI Agent Notes

Before working in this repository, check `GOAL.md`, `TODO.md`,
`DECISIONS.md`, and `HANDOFF.md` when they exist. These files record the current
objective, active tasks, decisions, and handoff notes for AI agent work.
